# FAssistant - приложение для финансвого учета

## Работа с проектом

1. `npm run dev` - запуск проекта в режиме разработки
2. `npm run build` - сборка проекта
3. `npm run lint` - запуск линтера
4. `npm run preview` - запуск превью проекта
5. `npm run chakra` - генерация типов чакра
6. `npm run test` - запуск тестов

## Работа с ИИ

AI используется в проекте преимущественно как технический консультант, ревьюер и наставник, а не как основной разработчик.

Доступны следующие роли:

`Tech Lead` — обсуждение архитектуры, паттернов и технических решений до реализации.
`Reviewer` — ревью готового кода, поиск ошибок, архитектурных проблем, уязвимостей и проблем производительности.
`Testing` — помощь с проектированием и ревью тестов.

Агенты не изменяют код без явного запроса.

### Claude Code

Для работы с Claude Code используются CLAUDE.md и конфигурация в .claude/. Общие правила проекта находятся в AGENTS.md, поэтому они не привязаны к конкретному AI-инструменту.

Специализированных агентов можно вызывать явно по необходимости:
`reviewer`, `tech-lead` или `testing`.

## Архитектура

В проекте используется архитектура [FSD](https://fsd.how)

### Слои

```text
app
 ↓
pages
 ↓
widgets
 ↓
features
 ↓
entities
 ↓
shared
```

| Слой       | Может обращаться к                                   |
| ---------- | ---------------------------------------------------- |
| `app`      | `pages`, `widgets`, `features`, `entities`, `shared` |
| `pages`    | `widgets`, `features`, `entities`, `shared`          |
| `widgets`  | `features`, `entities`, `shared`                     |
| `features` | `entities`, `shared`                                 |
| `entities` | `shared`                                             |
| `shared`   | `shared`                                             |
